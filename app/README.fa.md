# یادگیری فارسی

یک برنامهٔ وب پیشرونده (PWA) برای آموزش الفبای فارسی و ریاضی پایه به مبتدیان کامل، طراحی‌شده برای کاربران سالمند غیرخواننده.

## معرفی

یادگیری فارسی یک PWA کامل و حرفه‌ای است که با الهام از Duolingo و Brilliant.org ساخته شده و به‌طور خاص برای یک خانم ۵۰ سالهٔ ایرانی که هرگز به مدرسه نرفته، طراحی شده است. این برنامه دو مسیر آموزشی دارد:

1. **مسیر عددها و حساب**: ریاضی پیش‌دبستانی از صفر مطلق - شمردن ۰ تا ۱۰، جمع و تفریق ساده، پول، ساعت
2. **مسیر الفبا و خواندن**: الفبای فارسی و خواندن مقدماتی از ابتدا - شناخت حروف، آواها، کلمات ساده

## ویژگی‌ها

### تجربهٔ یادگیری اصلی
- **بیش از ۶۳۵ تمرین** در ۸ بخش برای هر مسیر
- **بیش از ۱۵ نوع تمرین**: کارت‌های معرفی، انتخاب تصویر، گوش دادن و انتخاب، شمردن اشیا، کشیدن حروف، جفت کردن، خط اعداد، معادلات، پول، ساعت و بیشتر
- **طراحی صدا محور**: Web Speech API + فایل‌های MP3 از پیش ساخته‌شده برای دستگاه‌های بدون TTS فارسی
- **بدون نیاز به تایپ**: همهٔ تعاملات از طریق لمس، کشیدن یا رسم
- **بازخورد ملایم**: بدون قلب‌های تنبیهی - اشتباه اول راهنمایی و تلاش مجدد، اشتباه دوم پاسخ را نشان می‌دهد

### بازی‌سازی
- **سیستم امتیاز (XP)**: کسب امتیاز برای پاسخ‌های درست
- **پیگیری روزهای پی‌درپی**: با ۲ روز استراحت در هفته
- **اهداف روزانه**: تعیین تعداد درس‌های روزانه
- **مسیر بصری**: نمایش بخش‌ها و درس‌های باز و قفل‌شده
- **جشن**: کنفتی، صداها، لرزش، انیمیشن‌ها

### دسترس‌پذیری
- **چیدمان راست به چپ**: رابط کاربری صحیح فارسی
- **متن بزرگ**: متن بدنه ۲۲ پیکسل+، سؤالات ۲۶ پیکسل+، پاسخ‌ها ۷۲-۸۴ پیکسل
- **دکمه‌های بزرگ**: همهٔ دکمه‌ها ۵۶ پیکسل+، دکمه‌های اصلی ۶۴ پیکسل
- **کنتراست بالا**: همهٔ جفت‌های متنی ۷:۱ یا بهتر
- **اعداد فارسی**: در سراسر رابط کاربری (۰-۹)
- **صدا همه‌جا**: هر جمله، دکمه و گزینه می‌تواند خودش را بخواند

### برنامهٔ وب پیشرونده (PWA)
- **قابل نصب**: آیکون صفحهٔ اصلی، حالت مستقل
- **قابل استفاده آفلاین**: Service worker محتوا و تمرین‌ها را ذخیره می‌کند
- **بدون بک‌اند**: همهٔ پیشرفت به‌صورت محلی در IndexedDB ذخیره می‌شود
- **بدون نیاز به حساب کاربری**: حریم خصوصی محور، بلافاصله کار می‌کند

## شروع کار

### نصب

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# ساخت نسخهٔ نهایی
npm run build

# اجرای سرور تولید
npm start
```

[http://localhost:3000](http://localhost:3000) را در مرورگر با نمای موبایل (۳۹۰×۸۴۴ توصیه می‌شود) باز کنید.

### تست

```bash
# تست‌های واحد
npm test

# تست‌های E2E
npm run test:e2e
```

## ساختار پروژه

```
app/
├── app/                     # Next.js App Router
│   ├── page.tsx            # نقطهٔ ورود / راه‌اندازی اولیه
│   ├── home/               # مسیر درس
│   ├── lesson/[id]/        # پخش‌کنندهٔ درس
│   ├── lesson-complete/    # صفحهٔ جشن
│   ├── streak/             # روزهای پی‌درپی و هدف روزانه
│   ├── profile/            # پروفایل و پیشرفت کاربر
│   └── globals.css         # توکن‌های طراحی و استایل‌های پایه
├── components/
│   ├── Onboarding.tsx      # جریان راه‌اندازی اولیهٔ ۵ مرحله‌ای
│   └── exercises/          # رندرکننده‌های تمرین (۱۵+ نوع)
├── lib/
│   ├── types.ts            # تعاریف TypeScript
│   ├── content.ts          # بارگذاری محتوا و ناوبری
│   ├── progress.ts         # مدیر پیشرفت IndexedDB
│   └── audio.ts            # Web Speech API + fallback MP3
├── public/
│   ├── content/            # math.json, alphabet.json
│   ├── fonts/              # فایل‌های woff2 وزیرمتن
│   ├── icons/              # آیکون‌های PWA
│   ├── audio/              # MP3های از پیش ساخته‌شده (اختیاری)
│   ├── manifest.json       # مانیفست PWA
│   └── sw.js               # Service worker
└── docs/                   # مواد طراحی
```
